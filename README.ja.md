# 韓国ライトノベル一覧

[一覧を見る](https://cjangcjengh.github.io/korean-light-novel-catalog/?lang=ja) · [한국어](README.md) · [English](README.en.md) · [中文](README.zh.md)

単行本として刊行された韓国ライトノベル281作品を、第1巻の発売日順に掲載。著者、イラスト担当、レーベル、巻数、作品紹介、各巻の表紙と出典を収録しています。

書誌データは `data/catalog.json`、表紙画像は `covers/` にあります。各作品・各巻のリンクから出典を確認できます。
