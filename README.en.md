# Korean Light Novel Catalog

[Browse](https://cjangcjengh.github.io/korean-light-novel-catalog/?lang=en) · [한국어](README.md) · [中文](README.zh.md)

281 Korean light novel series published in volumes, ordered by first-volume publication date. Includes authors, illustrators, imprints, volume counts, synopses, individual covers, and sources.

The catalog is in `data/catalog.json`, with covers in `covers/`. Sources are linked by work and volume.
