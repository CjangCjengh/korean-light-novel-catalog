# 한국 창작 라이트노벨 목록

[목록 보기](https://cjangcjengh.github.io/korean-light-novel-catalog/) · [English](README.en.md) · [中文](README.zh.md)

단행본으로 출간된 한국 창작 라이트노벨 264작품. 첫 권 출간일순으로 정리했으며, 작가·일러스트레이터·출판 브랜드·권수·소개·권별 표지와 출처를 수록했습니다.

완결 여부, 출판 브랜드, 연도, 권수, 작가, 일러스트레이터, 외전, 드라마 CD, 웹판 완결 여부로 검색·필터링할 수 있습니다. 검색 링크 공유와 CSV 저장을 지원하며, 즐겨찾기는 사용 중인 브라우저에 저장됩니다.

자료 기준: 2026.10.25. 날짜는 첫 권과 최근 권의 출간일입니다. 미완결 상태로 2년 이상 후속 권이 나오지 않은 작품은 ‘출간 중단’으로 분류했습니다. 단행본이 미완결이고 웹판이 완결된 경우에만 웹판 완결을 표시합니다.

자료는 `data/catalog.json`, 표지는 `covers/`에 있습니다. 출처는 작품별·권별 서점 링크에 연결되어 있습니다. 중국어·영어 제목에는 목록 작성을 위한 번역명이 포함되어 있습니다.
