# 韩国原创轻小说书目

[查看书目](https://cjangcjengh.github.io/korean-light-novel-catalog/?lang=zh) · [한국어](README.md) · [English](README.en.md)

收录264部按卷出版的韩国原创轻小说，按首卷发行日排列，整理作者、插画师、出版品牌、卷数、简介、逐卷封面及来源。

支持按完结状态、出版品牌、年份、卷数、作者、插画师、番外、广播剧CD和web版完结情况检索筛选，可分享筛选链接、导出CSV。收藏保存在当前浏览器中。

资料截至2026.10.25。日期为首卷和最新卷发行日。未完结且超过2年未出续卷的作品标为“太监”；仅文库版未完结而web版完结时另标web版完结。

书目在 `data/catalog.json`，封面在 `covers/`，来源见各作品及各卷的书店链接。中英文书名包含为本书目翻译的译名。
